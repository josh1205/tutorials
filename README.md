# Programming Tutorials Repository

A comprehensive collection of programming tutorials and learning projects covering multiple technologies and frameworks.

## 📚 Repository Structure

This repository contains tutorials and practice projects organized by technology:

### 🌐 Frontend Technologies

#### HTML & CSS
- **MarioClub**: A themed website project demonstrating HTML structure and CSS styling
- **TutorialStuff**: Basic HTML tutorials with forms, styling, and various web elements

#### JavaScript
- **newTutorial**: Modern JavaScript practices and examples
- **oldTutorial**: Foundational JavaScript concepts and introductory materials

#### React
- **dojo-blog**: A complete React blog application with routing and component management
  - Uses React 17.0.2 with React Router DOM
  - Includes testing setup with Jest and React Testing Library

#### Vue.js
- **dojo-blog**: Vue.js blog implementation
- **ninja-jobs**: Job listing application
- **reaction-timer**: Interactive timing game
- **web-form**: Form handling and validation examples

#### Material-UI
- **netninja**: Material-UI tutorial project
  - React application using Material-UI components
  - Includes icons and routing implementation

#### TypeScript
- Basic TypeScript configuration and practice files
- Configured for modern ES features with DOM support
- **typescriptReact**: TypeScript implementation with React

### 🔗 Blockchain & Web3

#### NFTs & Smart Contracts
- **AAVE_BROWNIE_PY**: AAVE protocol integration with Brownie framework
- **brownie**: Smart contract development environment setup
- **brownie_fundme**: Crowdfunding smart contract project
- **ERC20-BROWNIE**: ERC20 token implementation
- **nft**: Complete NFT project with metadata and deployment scripts
- **nft-demo**: NFT demonstration project
- **smartcontractlottery**: Lottery smart contract implementation
- **web3_py_simple_storage**: Basic Web3.py integration example

### 🖥️ Backend Technologies

#### PHP
- **tuts**: PHP tutorials covering basic syntax, forms, and templating

#### C# (.NET)
- **ArgsInfo**: Command line arguments handling
- **Delagates1**: Delegate pattern implementation
- **enumerations**: Enum usage and best practices
- **EventsAndDelegates**: Event-driven programming patterns
- **MultArrays**: Multi-dimensional array operations
- **Nullable**: Nullable types and null safety
- **RegexT & RegularExpressions**: Regular expression tutorials

### 📱 Mobile Development

#### Swift (iOS)
- **Constraints**: Auto Layout and constraint management
- **Firstappdesign**: Initial app design principles
- **StackviewsExercise**: Stack view implementation
- **WarCardGame**: Complete card game application
- Various playgrounds for Swift fundamentals

## 🚀 Getting Started

### Prerequisites
- Node.js and npm (for React, Vue, TypeScript projects)
- Python 3.x (for blockchain/NFT projects)
- PHP (for PHP tutorials)
- .NET Core SDK (for C# projects)
- Xcode (for Swift projects)

### Running Projects

#### React/Vue/TypeScript Projects
```bash
cd [project-directory]
npm install
npm start
```

#### NFT/Blockchain Projects
```bash
pip install eth-brownie
cd [project-directory]
brownie run scripts/deploy.py
```

#### PHP Projects
```bash
php -S localhost:8000
```

## 📖 Learning Path Suggestions

1. **Web Development Beginners**: Start with `HTMLCSS/` → `Javascript/` → `react/` or `vue/`
2. **Blockchain Development**: Begin with `NFTs/web3_py_simple_storage/` → `NFTs/brownie/` → `NFTs/nft/`
3. **Mobile Development**: Explore `swift/` projects starting with playgrounds
4. **Backend Development**: Check out `PHP/tuts/` for server-side basics
